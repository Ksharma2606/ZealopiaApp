# Figma ↔ Screen Mapping — Zealopia React Native App

Static inventory of every route/screen in `zealopia_new_app`, generated by inspecting `app/`, `components/`, `assets/`, `theme/`, and `constants/` on disk. No files were modified to produce this report.

**Methodology note on Figma node IDs:** this session has no live Figma file/URL access. Node IDs below are included only where they were explicitly recorded in `react_native_rewrite_progress.md` from a prior session's Figma inspection (Login, Number Entering). Everywhere else, "Figma Node" is marked `Unknown` (a frame name exists but no node ID was ever recorded) or `N/A` (no Figma export/reference for that screen exists anywhere in the repo). Nothing below is a guess at a node ID.

Routing is 100% Expo Router file-based routing under `app/` — there is no separate `screens/` directory. `components/screens/ChatHomeScreen.tsx` is the one exception: a screen-sized component rendered by the thin route file `app/(tabs)/chats.tsx`.

## 1. `(auth)` route group

Stack navigator defined in [app/(auth)/_layout.tsx](app/(auth)/_layout.tsx) (`initialRouteName: 'login'`). This group is the app's overall initial route (`app/_layout.tsx` → `initialRouteName: '(auth)'`). Auto-navigation between these screens (outside of each screen's own explicit `router.push/replace` calls) is centrally controlled by [components/RouteGuard.tsx](components/RouteGuard.tsx), summarized once here rather than repeated per screen:

- **Not authenticated:** only `login`, `otp-verify`, `splash` are allowed inside `(auth)`; anything else forces `router.replace('/login')`.
- **Authenticated but `!isSignupComplete`:** only `profile-setup`, `zora-intro`, `soul-colour`, `soul-colour-answer` are allowed inside `(auth)`; anything else forces `router.replace('/profile-setup')`.
- **Authenticated and signup complete:** only `zora-intro`, `soul-bot-chat` remain allowed inside `(auth)`; anything else forces `router.replace('/(tabs)')`.

`welcome` and `topics` are **not** in either allowlist — see their entries below.
